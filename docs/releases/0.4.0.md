# Caudal 0.4.0 · primera edición pública de prueba

Tu dinero, con perspectiva. Registro manual de ingresos, gastos, cuentas, transferencias, presupuestos, reservas de ahorro, deudas e informes en una app local para Mac.

## Descargas

- **Caudal-0.4.0-arm64.dmg**: arrastra la aplicación a Aplicaciones.
- **Caudal-0.4.0-arm64-app.zip**: bundle .app comprimido.
- **Caudal-0.4.0-src.zip**: fuentes del commit exacto declarado en el manifiesto.
- **Caudal-0.4.0-manifest.json** y **SHA256SUMS.txt**: procedencia y hashes.

El manifiesto identifica commit, arquitectura, objetivo macOS, herramientas y firma. Los paquetes iniciales proceden de una compilación local comprobada; el workflow prepara borradores independientes y no sustituye silenciosamente una release existente.

## Qué cambia

Edición pública y Caudal Dev con almacenamiento propio; arranque vacío; identidad Caudal con fondo vectorial original; documentación, pruebas y distribución reproducible. No se importan datos de otras ediciones automáticamente.
