# Imágenes públicas

Todas las capturas muestran datos ficticios de la ejecución UI registrada en docs/VERIFICACION.md. Se obtienen de WebKit real dentro de Caudal con CAUDAL_DATA aislado. No representan finanzas de una persona y no se incluyen en el arranque del producto.

- overview-dark.jpg, movements.jpg, budgets.jpg, savings.jpg, debts.jpg: capturas de vistas reales en modo oscuro.
- overview-light.jpg: captura real del tema claro.
- empty.jpg: primer arranque vacío.
- hero.png: portada promocional compuesta mediante scripts/cover.swift, con símbolo e interfaz de demostración. No es una captura íntegra de ventana.

El fondo caudal-flow.svg es un recurso original de la edición pública. No se usa la fotografía de ediciones personales anteriores. No se incluyen metadatos de identidad personal.
