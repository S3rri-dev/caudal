# Roadmap

Sin fechas ni compromisos de entrega. La prioridad se decide con problemas reproducidos durante uso real.

## Próximas mejoras a estudiar

- Pruebas con más Mac/versiones de macOS, VoiceOver y grandes históricos.
- Firma Developer ID y notarización, si se dispone de identidad y cuenta adecuadas.
- Mejoras de captura, filtros, archivado y conservación de copias.
- Importación CSV con validación y vista previa; no existe en 0.4.

## Posibilidades posteriores

Conexión bancaria, inversiones, sincronización entre dispositivos, versión móvil, multimoneda y funciones de IA. Requieren diseño y autorización propios; no forman parte del producto actual ni de promesas de esta release.
