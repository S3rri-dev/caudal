# Seguridad

Se atiende la versión pública más reciente. Usa **Report a vulnerability** en https://github.com/S3rri-dev/caudal/security/advisories/new para un reporte privado. Si la función no aparece disponible, abre una incidencia que solo pida un canal privado; no publiques detalles explotables o datos financieros.

Incluye versión, macOS, pasos mínimos con datos ficticios, impacto y comportamiento esperado. Nunca envíes una base personal, claves o extractos bancarios. No hay un plazo de respuesta garantizado ni programa de recompensas.

Caudal almacena SQLite sin cifrado propio, no usa App Sandbox y conserva historial/copias. No hay auditoría externa de seguridad. Consulta docs/PRIVACY.md y docs/DATA.md para límites y conservación.

Las releases iniciales tienen firma ad hoc y carecen de Developer ID/notarización. La verificación de hashes ayuda a comprobar integridad, pero no equivale a una identidad de desarrollador certificada por Apple.
