| Recurso | Procedencia y condiciones |
| --- | --- |
| Swift, Foundation, AppKit, WebKit | Herramientas/frameworks de Apple enlazados desde el sistema. No se redistribuyen sus SDK ni sus fuentes. Las excepciones de bibliotecas del sistema de la GPL son aplicables según sus términos. |
| SQLite | Biblioteca del sistema, enlazada como sqlite3. SQLite declara su código en dominio público: https://sqlite.org/copyright.html. No se empaqueta una copia de la biblioteca. |
| Iconos de interfaz | Trazados SVG sencillos escritos para Caudal en app.js; no se importa una librería de iconos. |
| Tipografías | Baskerville/Georgia y familia del sistema por nombre. No se distribuyen archivos de fuentes. |
| C de ondas e iconos de marca | Concepto generado con asistencia de IA para este proyecto, seleccionado y reconstruido como curvas SVG. La geometría compartida está en caudal-paths.json; el icono se genera con scripts/icon.swift. No se garantiza exclusividad de un resultado generado ni se afirma registro de marca. Uso: TRADEMARKS.md. |
| Fondo caudal-flow.svg | Ilustración vectorial original escrita para la edición pública; GPL-3.0-or-later. Sin fotografías o texturas externas. |
| Portada | Composición promocional creada con scripts/cover.swift, símbolo del proyecto y captura real de demostración. No es una captura íntegra de una ventana. |
| Capturas docs/images | Interfaz real de AppKit/WebKit con datos ficticios creados por las pruebas. La descarga empieza vacía. |

La fotografía usada en una edición personal anterior no se incluye: no se ha acreditado permiso de redistribución. Tampoco se incluyen tableros de propuestas ni capturas antiguas.

La organización documental toma como referencia Nodal (https://github.com/S3rri-dev/nodal) y vorssaint-utils (https://github.com/vorssaint/vorssaint-utils). No se incorpora código ni identidad de vorssaint-utils. Caudal es independiente de ambos proyectos.

Las acciones de GitHub se ejecutan en CI desde sus repositorios, fijadas por commit; no forman parte del binario descargable.
